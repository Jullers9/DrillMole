# Ответы на ревью DrillMole

Автор: Резниченко Илья. Дата: 26.10.2026.
Ответы относятся к версии 1.0. Правки выполнены до заморозки.

## Арина Полякова — ревью B, PR #3

| № | Замечание | Решение и результат |
|---|---|---|
| 1 | Мгновенный выезд на поверхность | Принято как уточнение модели. Глубина не моделируется, отдельная стоимость перехода не учитывается; оплачивается участок поверхности. SPEC 3.4.1, существующие TC-20 и TC-24 |
| 2 | Точность времени | Принято. Время отдельно не округляется, сравнение через assertAlmostEqual с 7 знаками. SPEC 3.5, TC-31 |
| 3 | Замена исправного бура | Принято. На поверхности успешная операция без изменения состояния, возвращает None. SPEC 3.4.5, TC-30 |
| 4 | Доступ только для чтения | Принято. Запись в любой из семи атрибутов вызывает AttributeError. Способ реализации остаётся за разработчиком. SPEC 3.3, TC-27 |
| 5 | Независимость get_status | Принято. Добавлена проверка двух словарей, изменения словаря и сохранности старого снимка после движения. SPEC 3.4.6, TC-29 |
| 6 | Ошибки calculate_fuel | Принято. Добавлены неверные типы, значения и проверка неизменности состояния. SPEC 3.5, TC-28 |
| 7 | Износ проверяется раньше топлива | Отклонено. Это приоритет диагностики, а не последовательность физических событий. Проверка не ломает бур и не меняет состояние. Правило однозначно задано в SPEC 3.5 и TC-12 |
| 8 | Нельзя подъехать к реке | Отклонено. Карты и координат препятствий нет. До реки можно ехать по surface, затем выбрать soil. Запрет water относится к движению в воде, а не к приближению к берегу. Пример уже есть в сценарии «Подкоп под крепость», TC-23 |

Рекомендации:

- Дата заморозки — принято: 26.10.2026, версия 1.0.
- Проверка точного текста ошибок — отклонено: для этого учебного контракта достаточно типа исключения. Тексты в SPEC 6.2 остаются примерами, обязательный формат не вводим.
- Заправка полного бака — принято: SPEC 3.4.4, TC-30.

## Святослав Сорокин — ревью C, PR #4

| № | Замечание | Решение и результат |
|---|---|---|
| 1 | Не определён запрет записи в атрибуты | Принято. Зафиксирован AttributeError и неизменность объекта. SPEC 3.3, TC-27 |
| 2 | Валидация calculate_fuel и refuel не покрыта | Принято. Добавлены проверки типов (в том числе bool), значений и атомарности. TC-28 |
| 3 | Стена проходима на поверхности | Принято. Теперь нужны is_underground и drill_wear < 100. Проверка проходимости не выполняет движение и не проверяет запас топлива. SPEC 3.4.2, обновлён TC-15; сценарии подкопа этому соответствуют |

Рекомендации:

- Пробельное имя — принято: имя должно содержать непробельный символ. SPEC 3.2, TC-01.
- NaN и бесконечность — принято: во всех числовых аргументах вызывают ValueError. SPEC 3.2, TC-32.
