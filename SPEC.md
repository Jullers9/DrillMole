## 1. Назначение

Крот-бур «Копатель» — одноместная машина, которая ездит по поверхности и прокапывает ходы под землёй с помощью бура в передней части. Под землёй можно пройти там, где по поверхности не проехать: под рекой или под стеной. Плавать не умеет, бур со временем изнашивается и его нужно менять.

## 2. Стихия и конструкционный элемент

Стихия: земля.

Конструкционный элемент: бур — элемент, за счёт которого машина движется в грунте.

Как реализован элемент:
- `drill_diameter_m` — диаметр бура. От него зависит, сможет ли крот расколоть валун.
- `drill_wear` — износ бура в процентах (0…100). Растёт при движении под землёй. Изношенным буром нельзя копать дальше, бур меняется методом `replace_drill` и только на поверхности.

Ограничения стихии:
- Основной режим — движение в грунте и по поверхности.
- В воду заезжать нельзя.
- Под землёй (в грунте и в скале) движение медленнее, расходуется больше топлива и изнашивается бур.

## 3. Публичный интерфейс

### 3.1. Класс

Имя класса: `DrillMole`
Модуль: `drill_mole.py`

### 3.2. Конструктор

```python
def __init__(
    self,
    name: str,
    drill_diameter_m: float,
    max_speed_kmh: float,
    fuel: float = 100.0,
) -> None:
```

| Параметр | Тип | Единица | Допустимый диапазон | По умолчанию |
|---|---|---|---|---|
| name | str | — | хотя бы один непробельный символ | — |
| drill_diameter_m | float | м | > 0 | — |
| max_speed_kmh | float | км/ч | > 0 | — |
| fuel | float | условные единицы | 0 … 100 | 100.0 |

Во всех методах числовые параметры принимают `int` и `float`, `bool` не допускается. Числа должны быть конечными: `NaN`, `inf` и `-inf` вызывают `ValueError` после проверки типа.

Исключения конструктора:
- `TypeError` — если `name` не строка или числовой параметр не `int`/`float` (в т.ч. `bool`).
- `ValueError` — если `name` пустой или состоит только из пробельных символов. Допустимое имя сохраняется без изменения.
- `ValueError` — если `drill_diameter_m` или `max_speed_kmh` ≤ 0.
- `ValueError` — если `fuel` вне диапазона 0…100.

После создания: `position_km == 0.0`, `drill_wear == 0.0`, `is_underground == False` (крот на поверхности). Начальный `fuel` сохраняется без округления, после приведения к `float`.

### 3.3. Атрибуты

Все перечисленные атрибуты доступны только для чтения. Присваивание любому из них вызывает `AttributeError` и не меняет состояние. Способ реализации этого ограничения не регламентируется.

| Атрибут | Тип | Единица | Доступ | Описание |
|---|---|---|---|---|
| name | str | — | чтение | Имя |
| drill_diameter_m | float | м | чтение | Диаметр бура |
| max_speed_kmh | float | км/ч | чтение | Скорость по поверхности |
| fuel | float | условные единицы | чтение | Запас топлива, 0…100 |
| drill_wear | float | % | чтение | Износ бура, 0…100 |
| position_km | float | км | чтение | Пройденное расстояние (суммарно) |
| is_underground | bool | — | чтение | Находится ли крот под землёй |

### 3.4. Методы

#### 3.4.1. move

```python
def move(self, distance_km: float, terrain: str) -> float:
```

Назначение: перемещает крота на заданное расстояние в заданной среде.

Параметры:
- `distance_km` — расстояние в км, > 0.
- `terrain` — среда: `"surface"` (поверхность), `"soil"` (грунт), `"rock"` (скала), `"water"` (вода).

Возвращает: время в часах (`float`).

Изменяет: `position_km`, `fuel`, `drill_wear`, `is_underground`.

Правила:

| terrain | Скорость | Расход топлива | Износ бура | is_underground после |
|---|---|---|---|---|
| surface | max_speed_kmh | distance_km × 1 | 0 | False |
| soil | max_speed_kmh × 0.5 | distance_km × 2 | distance_km × 1 | True |
| rock | max_speed_kmh × 0.25 | distance_km × 3 | distance_km × 5 | True |
| water | — | — | — | DrillMoleCannotSwim |

- Если топлива хватает ровно, движение успешно и `fuel` становится 0.
- При сравнении расхода с положительным запасом допускается абсолютная погрешность `1e-9`; при `fuel == 0` любое движение запрещено. Расход для сравнения и `calculate_fuel` отдельно не округляется.
- Если износ после движения будет ровно 100, движение успешно. Если больше 100 — `DrillMoleDrillWorn`.
- При износе 100 любое движение в грунте или скале запрещено, даже если последующее округление оставило бы значение 100. Проверка превышения выполняется до округления состояния.
- При любом исключении состояние не меняется.
- Переход между поверхностью и подземным режимом входит в вызов `move`: отдельные глубина, время и стоимость въезда/выезда не моделируются. Поэтому `move(..., "surface")` допустим из-под земли даже при износе 100; оплачивается только указанный участок поверхности.

Исключения:
- `TypeError` — `distance_km` не число или `terrain` не строка.
- `ValueError` — `distance_km` ≤ 0 или `terrain` не из списка.
- `DrillMoleCannotSwim` — `terrain == "water"`.
- `DrillMoleDrillWorn` — `drill_wear` + износ за перемещение > 100 (только для soil и rock).
- `DrillMoleNoFuel` — `fuel` меньше расхода на перемещение.

#### 3.4.2. can_overcome

```python
def can_overcome(self, obstacle: str) -> bool:
```

Назначение: проверяет проходимость препятствия по текущему режиму и характеристикам. Само перемещение не выполняет, топливо не расходует и его запас не проверяет: расстояние до препятствия не задано. Состояние не меняет.

Параметры:
- `obstacle` — `"river"`, `"wall"`, `"boulder"`.

Возвращает: `True` / `False`.

Правила:
- `"river"` — только если `is_underground` (проходит под рекой).
- `"wall"` — только если `is_underground` и `drill_wear < 100` (подкоп под стеной).
- `"boulder"` — только если `drill_diameter_m >= 1.0`.

Исключения:
- `TypeError` — `obstacle` не строка.
- `ValueError` — `obstacle` не из списка.

#### 3.4.3. calculate_fuel

```python
def calculate_fuel(self, distance_km: float, terrain: str) -> float:
```

Назначение: считает расход топлива на перемещение, не меняя состояние.

Параметры и формула расхода — как у `move`. Текущий запас топлива и износ бура не проверяются.

Исключения: `TypeError`, `ValueError`, `DrillMoleCannotSwim` — как у `move`.

#### 3.4.4. refuel

```python
def refuel(self, amount: float) -> None:
```

Назначение: заправка. `fuel` увеличивается на `amount`, но не выше 100. При полном баке положительная заправка успешно возвращает `None`, запас остаётся 100.

Исключения:
- `TypeError` — `amount` не число.
- `ValueError` — `amount` ≤ 0.

#### 3.4.5. replace_drill

```python
def replace_drill(self) -> None:
```

Назначение: замена бура, `drill_wear` становится 0. Топливо не расходуется. На поверхности замена исправного бура тоже успешна: возвращается `None`, состояние не меняется. Под землёй запрет действует при любом износе.

Исключения:
- `DrillMoleNotOnSurface` — если крот под землёй (`is_underground == True`).

#### 3.4.6. get_status

```python
def get_status(self) -> dict:
```

Возвращает новый независимый словарь с ключами (изменение словаря не влияет на объект):
- `"name"` — str,
- `"fuel"` — float,
- `"drill_wear"` — float,
- `"position_km"` — float,
- `"is_underground"` — bool.

### 3.5. Общие правила

- Порядок проверок: параметры по порядку в сигнатуре (для каждого сначала тип, потом значение), затем вода, затем износ бура, затем топливо.
- После каждого изменения `fuel`, `drill_wear` и `position_km` округляются до 6 знаков после запятой (чтобы 0.3 − 0.1 − 0.1 − 0.1 давало 0, а не −2.7e-17).
- Возвращаемое время `move` не округляется отдельно: это результат деления расстояния на скорость в выбранной среде. Тесты сравнивают время через `assertAlmostEqual(..., places=7)`.
- При ошибках валидации и доменных исключениях любого метода состояние не меняется.

## 4. Сценарии

### 4.1. Модульные (AAA)

Для всех сценариев, если не сказано иное: `name="Копатель"`, `drill_diameter_m=1.2`, `max_speed_kmh=20`, `fuel=100`.

**Сценарий 1. Движение в грунте**
Дано: новый крот.
Когда: `move(10, "soil")`.
Тогда: возвращается 1.0 (10 / 10); `position_km == 10`; `fuel == 80`; `drill_wear == 10`; `is_underground == True`.

**Сценарий 2. Не хватает топлива**
Дано: `fuel = 10`.
Когда: `move(4, "rock")` (нужно 12).
Тогда: `DrillMoleNoFuel`, состояние не меняется.

**Сценарий 3. Река**
Дано: крот под землёй (после `move(1, "soil")`).
Когда: `can_overcome("river")`.
Тогда: `True`.

**Сценарий 4. Замена бура**
Дано: после `move(10, "rock")` износ 50, затем `move(1, "surface")`.
Когда: `replace_drill()`.
Тогда: `drill_wear == 0`, `fuel == 69` не изменился.

### 4.2. Сценарные (GWT)

Тесты ведутся через обёртку-машиниста `Driver` (tests/driver.py), который управляет кротом.

### Сценарий: Подкоп под крепость

**Given:** «Копатель» с `drill_diameter_m = 1.2`, `max_speed_kmh = 20`, `fuel = 100` на поверхности

**When:** машинист едет 2 км по поверхности к реке
**Then:** время 0.1 ч, `fuel == 98`, `position_km == 2`, крот на поверхности

**When:** машинист проверяет реку
**Then:** `False` — по поверхности реку не пройти

**When:** машинист зарывается и проходит 4 км в грунте
**Then:** время 0.4 ч, `fuel == 90`, `drill_wear == 4`, крот под землёй
**And:** река теперь проходима (`True`)

**When:** машинист проходит под рекой ещё 3 км
**Then:** `fuel == 84`, `drill_wear == 7`, `position_km == 9`

**When:** машинист проверяет стену крепости
**Then:** `True` — бур не изношен, можно сделать подкоп

**When:** машинист выезжает на поверхность внутри крепости, 2 км
**Then:** `position_km == 11`, `fuel == 82`, `drill_wear == 7`, крот на поверхности

### Сценарий: Скальный пласт и сломанный бур

**Given:** «Копатель» с `fuel = 100`, `max_speed_kmh = 20`

**When:** машинист проходит 10 км скалы
**Then:** время 2.0 ч, `fuel == 70`, `drill_wear == 50`

**When:** машинист проходит ещё 10 км скалы
**Then:** `fuel == 40`, `drill_wear == 100`, `position_km == 20`
**And:** стену уже не подкопать (`False`)

**When:** машинист пытается пройти 1 км грунта
**Then:** `DrillMoleDrillWorn`, состояние не меняется

**When:** машинист пытается заменить бур под землёй
**Then:** `DrillMoleNotOnSurface`

**When:** машинист выезжает на поверхность (1 км) и меняет бур
**Then:** `fuel == 39`, `position_km == 21`, `drill_wear == 0`

**When:** машинист снова зарывается на 2 км в грунт
**Then:** `fuel == 35`, `drill_wear == 2`, `position_km == 23`, крот под землёй

### Сценарий: Река и пустой бак

**Given:** «Копатель» с `drill_diameter_m = 0.8`, `fuel = 10`

**When:** машинист едет 5 км по поверхности
**Then:** `fuel == 5`, `position_km == 5`
**And:** валун не расколоть (`False`, бур меньше 1 м)

**When:** машинист пытается переплыть реку (1 км по воде)
**Then:** `DrillMoleCannotSwim`, состояние не меняется

**When:** машинист пытается пройти под рекой 3 км грунта (нужно 6 топлива)
**Then:** `DrillMoleNoFuel`, `fuel == 5`

**When:** машинист заправляется на 200
**Then:** `fuel == 100`
**And:** расчёт `calculate_fuel(3, "soil")` даёт 6, состояние не меняется

**When:** машинист проходит под рекой 3 км
**Then:** `fuel == 94`, `drill_wear == 3`, `position_km == 8`, крот под землёй

### Сценарий: Маршрут по плану

**Given:** «Копатель» с `drill_diameter_m = 1.0`, `fuel = 50`

**When:** машинист считает расход на 5 км поверхности, 5 км грунта и 5 км скалы
**Then:** 5, 10 и 15 — всего 30, состояние не меняется

**When:** машинист проходит эти три участка
**Then:** `fuel == 20`, `drill_wear == 30`, `position_km == 15`, крот под землёй
**And:** валун можно расколоть (`True`)
**And:** `get_status()` возвращает `{"name": "Копатель", "fuel": 20.0, "drill_wear": 30.0, "position_km": 15.0, "is_underground": True}`

## 5. Граничные случаи

- `move(4, "rock")` при `fuel = 12` → успешно, `fuel == 0`.
- Износ ровно до 100 (два раза `move(10, "rock")`) → успешно; дальше `move(1, "soil")` → `DrillMoleDrillWorn`, но `move(1, "surface")` работает.
- `can_overcome("boulder")` при `drill_diameter_m = 1.0` → `True`, при 0.99 → `False`.
- `refuel(1000)` при `fuel = 50` → `fuel == 100`.
- `fuel = 0.3`, три раза `move(0.1, "surface")` → успешно, `fuel == 0.0`.

### 6.1. Иерархия


## 7. Что вне рамок

- Нет глубины: «под землёй» — просто признак `is_underground`, без координат и глубины.
- Нет направления и маршрута: `position_km` — суммарный путь.
- Нет взаимодействия с другими транспортами.
- Нет графики, сохранения состояния, работы с файлами и API.
- Не моделируются масса, грунтовые воды, обвалы, погода.
- Запас бура не ограничен: `replace_drill` можно вызывать сколько угодно.

## 9. Открытые вопросы

Для версии 1.1 открытых вопросов нет. По ревью зафиксировано:

- Присваивание публичным атрибутам запрещено (`AttributeError`).
- Стена проходима только под землёй с неизношенным буром. Проверка препятствия не учитывает топливо; расход проверяет `move`.
- Выезд на поверхность выполняется через `move(..., "surface")`, без отдельного действия и стоимости перехода.

Ответы на замечания — в [RESPONSES.md](RESPONSES.md). Изменения после заморозки — через [CHANGELOG.md](CHANGELOG.md) и regression-тест.
